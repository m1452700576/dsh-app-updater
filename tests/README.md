# Tests

This directory contains tests for the dsh-app-updater plugin.

## Running Tests

```bash
# Run all tests
npm test

# Run tests with coverage
npm run test:coverage

# Run tests in watch mode
npm run test:watch
```

## Test Structure

- `unit/` - Unit tests for individual functions
- `integration/` - Integration tests for plugin functionality
- `fixtures/` - Test fixtures and mock data
