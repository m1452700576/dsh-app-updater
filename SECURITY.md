## Reporting a Vulnerability

If you discover a security vulnerability in dsh-app-updater, please report it responsibly.

**Please do NOT open a public GitHub issue for security vulnerabilities.**

Instead, please send an email to: security@example.com (replace with actual email)

### What to include:
- Description of the vulnerability
- Steps to reproduce
- Potential impact
- Suggested fix (if any)

### Response Timeline:
- Initial response: Within 48 hours
- Vulnerability assessment: Within 1 week
- Fix and release: Depends on severity

## Security Features

dsh-app-updater includes several security measures:

1. **Download Confirmation**: Users must confirm before downloading
2. **Private IP Blocking**: Blocks downloads from private/local IPs
3. **SHA-256 Checksum**: Verifies downloaded files when available
4. **HTTPS Only**: All downloads use HTTPS
5. **Source Validation**: Validates update sources before downloading

## Best Practices

- Keep the plugin updated to the latest version
- Only download updates from trusted sources
- Verify checksums when provided
- Report any suspicious behavior immediately
